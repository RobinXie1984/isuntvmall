# iSunTVMall identity

The fixed brand lockup is the comet emblem + iSunTVMall above 陽光精選. Navigation and commerce copy remain locale-switched. Header and footer share BrandMark.

Reference: https://isuntv.com/isuntv-logo.png, inspected 26 September 2026. A transparent emblem derivative was prepared with built-in image_gen, then resized for browser/touch/manifest use. It is a reference-based derivative, not a recovered original vector.

Prompt: Extract only the existing golden comet-ball emblem; preserve proportions, sweep direction, red-green-blue color order and gradient; remove all lettering and dark background; transparent square with modest padding; no additional elements.

`isuntvmall-logo.svg` is the reusable stacked lockup, with embedded emblem and live text. `comet.png` is the shared website emblem. Browser icons use the emblem alone for legibility.
