# MUJI — Quiet essentials

iSunTVMall style direction, saved 2026-09-25. The folder name is an internal reference label, not a brand affiliation. This is an original interpretation; do not use reference-brand logos, proprietary typefaces, house patterns or copied photographs.

## Character

Warm paper, natural textures and useful things with room to breathe.

## Composition

A split editorial story, restrained olive controls and an open four-column catalogue. Keep the current storefront proportions.

Use the `tokens.json` colors and type stacks. Heading and body fonts use locally available system fallbacks. Preserve readable contrast, visible keyboard focus and one interface language at a time. On mobile, stack the story before the product grid; never shrink the desktop page into a miniature. Motion is optional and must respect reduced-motion preferences.

## Product photography and batch processing

Natural diffuse light; honest material detail; warm neutral canvas. No added props or recoloring.

The deterministic batch profile fits the complete source inside a square canvas, applies the configured margin, normalizes orientation, exports WebP at up to 1600 pixels and quality 85, and preserves the original separately. Canvas color only fills unused space or transparency. It is not background removal, image relighting or AI restyling. Do not silently erase objects, change labels, manufacture product features or upscale small images without a quality flag. A super administrator must review original and output before publication.

## Interface application

The `/styles` gallery scopes this preset to its preview panel. Choosing it never changes the live storefront, the shopping bag or a merchant's saved configuration. The deployed storefront remains `muji`. A future theme rollout must apply the full component system and verify mobile, checkout and language behavior before activation.
