## Working daily sequence

[Products](https://www.isuntvmall.com/admin/products) → **Import** → choose/replace a Shopify CSV or Excel `.xlsx` → **Upload file** → **Preview your first product** → **Import products** → results with draft/photo links and a retry receipt. Batch import opens the same dialog. No collection name or local photo selection is required for product-data import. First worksheet only; 2 MB, 500 products, 10,000 rows. Existing product and variant services are reused.

The signed-in Shopify reference showed the same file/upload/preview/confirmation sequence, counts, first-product fields and variant table. Its final import was cancelled: SunTVMall was not changed. Shopify's overwrite/publish options are represented by an explicit fixed Mall policy: preserve existing public listings and colleague edits, and prepare new products privately. MUJI review and business approval remain separate.

Supported HTTPS `cdn.shopify.com/s/files/` references, including variant image references, enter the existing private MUJI queue automatically. URLs are deduplicated per product. Originals are immutable, processed output stays private, and no image is approved by import. Unsupported hosts, conflicts, quota holds and failed images require attention. Other original photos can still be uploaded manually. The existing worker/schedule is reused; no additional daemon, credential or dependency was added.

Merchandise Admin prepares details, translations, stock/price evidence and photos. Business Super Admin performs formal MUJI review and final approval. The current [admin manual](https://www.isuntvmall.com/admin/help#batch-import) explains the actual screens and recovery steps.
